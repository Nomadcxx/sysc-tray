## Protocol

Frozen at major 1, minor 0. The `protocol` package imports only the standard library, verified by
`go list -deps ./protocol`.

Message kinds: `hello`, `snapshot`, `item-added`, `item-changed`, `item-removed`, `menu-updated`,
`command`, `reply`.

Commands: `activate`, `secondary-activate`, `scroll`, `menu.open`, `menu.select`,
`menu.about-to-show`, `menu.close`.

Error codes: `invalid`, `stale_item`, `stale_revision`, `unavailable`, `busy`.

Framing is four-byte unsigned big-endian length prefixed JSON. The length is rejected before allocation.
Decoding is strict: unknown fields, duplicate keys, trailing values, and non-UTF-8 input are refused.

## Identity and safety invariants

- An item is identified by unique bus owner, object path, and generation. A reusable well-known name
  never identifies an item on its own.
- A replacement is published as a removal of the old generation followed by an addition of the new one.
- A refresh result naming a superseded generation is discarded.
- One malformed item, pixmap, menu, or property never removes a healthy sibling.
- Menu commands carry the revision the shell drew and are rechecked immediately before the D-Bus call.
- No command is retried after a timeout or connection loss, because the effect may already have occurred.
- The presenter socket lives at `$XDG_RUNTIME_DIR/sysc-tray/presenter.v1.sock`, mode `0600` inside a
  `0700` directory, with symlink and owner checks and an `SO_PEERCRED` UID check before the hello is read.
- Request IDs must strictly increase within a connection generation; a replay closes the connection.
- A presenter that overflows its queue is dropped without blocking D-Bus.

## Deviations from the plan

- **Command correlation lives only in the envelope.** The plan sketched a `RequestID` field inside
  `Command`. Carrying it in both the envelope and the payload invites the two to disagree, so the
  envelope owns it, matching the shipped `sysc-notify` protocol.
- **`internal/dbusval` was added.** Item and menu decoding both read attacker-controlled D-Bus values
  that arrive either as Go structs or as `[]interface{}` inside variants. The shared helpers keep that
  parsing in one place rather than duplicating it in two packages.
- **`internal/dbustest` was added.** The watcher name is global to a bus, and Go runs package tests in
  parallel processes, so a single shared bus made packages interfere. Each test now starts its own
  session daemon.
